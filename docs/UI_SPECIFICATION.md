## 📖 2. 화면별 UI 구성 요소 공식 명칭 사전

### 1️⃣ 엣지 핸들 (`Edge Handle`)
* **역할**: 평소 화면 한쪽에 작고 투명하게 떠 있는 제스처 바.
* **주요 구성**:
  - `핸들 바 (Handle Bar)`: 드래그하거나 탭하여 패널을 여는 터치 영역.
  - `핸들 위치/크기/투명도`: 설정에서 조절하는 두께, 길이, 투명도.

---

### 2️⃣ 엣지 패널 (`Edge Panel`)
* **역할**: 엣지 핸들을 당기거나 Good Lock 제스처로 열리는 메인 알림 서랍 화면.
* **구성 세부 명칭**:

| 영역 명칭 | 설명 | 코드 매핑 |
| :--- | :--- | :--- |
| **패널 헤더 (Panel Header)** | 패널 최상단 로고, 알림 개수 및 공통 버튼 줄 | `PanelHeader()` |
| └ **모두 지우기 버튼** | 누르면 수신된 모든 알림을 한 번에 정리하는 버튼 | `Clear All Button` |
| └ **설정 버튼** | 설정 액티비티로 이동하는 톱니바퀴 아이콘 | `Settings Icon` |
| └ **패널 닫기 버튼** | 패널을 닫는 상단 `X` 아이콘 | `Close Button` |
| **알림 카드 (Notification Card)** | 수신된 알림 1개를 감싸는 글래스모피즘 카드 컨테이너 | `NotificationCard()` |
| └ **카드 앱 헤더** | 앱 아이콘, 앱 이름, 단체방 경로(`› 방이름`), 수신 시각 | `Card Header Row` |
| └ **보관됨 뱃지** | 시스템 바에서 사라졌지만 패널에 기록 보존된 상태 라벨 | `Dismissed Badge` |
| └ **개별 삭제 버튼 (X)** | 해당 알림 카드만 목록에서 지우는 우측 상단 `X` 아이콘 | `Dismiss IconButton` |
| └ **카드 타이틀 (Card Title)** | 단체방 이름(참여자 목록) 또는 발신자 이름 | `Card Title Text` |
| └ **단체방 뱃지** | 단체방일 때 타이틀 앞에 붙는 청록색 `[단체방]` 라벨 | `Group Chat Badge` |
| └ **이전 대화 토글** | 과거 대화 내역(최대 50개)을 펼치거나 접는 버튼 | `History Toggle Row` |
| └ **발신자 라벨 (Sender Label)** | 말풍선 내용 앞에 붙는 청록색 `[발신자명]: ` | `Sender Label` |
| └ **메시지 본문 (Message Text)** | 실제 주고받은 메시지 내용 | `Message Content` |
| └ **메시지 수신 시각** | 각 말풍선 우측 하단에 표시되는 `오후 4:09` 형태의 시각 | `Message Timestamp` |
| └ **빠른 답장 버튼** | 누르면 키보드와 함께 플로팅 답장 바를 여는 `[답장]` 버튼 | `Quick Reply Button` |
| └ **데이터 복사 버튼** | 알림의 원본 extras 데이터를 클립보드로 복사하는 버튼 | `Debug Copy Button` |
| **플로팅 답장 바 (Floating Reply Bar)** | 가상 키보드 바로 위에 뜨는 빠른 답장 전용 입력창 | `KeyboardFloatingReplyBar()` |
| └ **답장 대상 라벨** | `답장: 김수환` 형태로 누구에게 보내는지 알려주는 상단 안내문 | `Target Name Label` |
| └ **답장 입력 필드** | 텍스트를 입력하는 곳 (자동 포커스) | `Reply BasicTextField` |
| └ **전송 버튼** | 작성한 메시지를 시스템 Quick Reply로 쏘아 보내는 버튼 | `Send IconButton` |

---

### 3️⃣ 설정 화면 (`Settings Screen`)
* **역할**: 앱의 모든 동작, 제스처, 글꼴, 업데이트를 관리하는 메인 설정 페이지.
* **구성 세부 명칭**:

| 카드 명칭 | 포함된 기능 및 설정 항목 |
| :--- | :--- |
| **마스터 스위치 카드** | 서비스 전체 ON / OFF 토글 |
| **권한 상태 카드 (Permissions Card)** | 알림 접근 권한, 다른 앱 위에 표시 권한, 배터리 최적화 예외 |
| **엣지 핸들 스타일 카드 (Handle Style)** | 위치(좌/우), Y축 위치, 높이, 너비, 투명도, 핸들 색상, 햅틱 피드백 |
| **패널 디자인 카드 (Panel Design)** | 패널 너비(Dp), 투명도, 블러 효과 강도 |
| **동작 설정 카드 (Behavior Settings)** | 앱 실행 시 알림 자동 지우기 여부, 알림 카드 탭 동작 |
| **글꼴 설정 카드 (Font Settings)** | 맑은 고딕, 프리텐다드, 나눔스퀘어, 원모바일고딕 등 폰트 선택 |
| **알림 원본 데이터 인스펙터** | 최근 수신 알림들의 Bundle Extras 구조 확인 및 `[전체 복사]` |
| **앱 업데이트 카드 (Update Card)** | GitHub 릴리즈 최신 버전 확인 및 원클릭 인앱 다운로드/설치 |
| **앱 정보 카드 (App Info Card)** | 버전명(`v1.4.9`), 빌드 번호(`Build 50`), Target SDK |

## 💬 3. 개발 지시 내릴 때 편한 명령어 템플릿 예시

앞으로 AI 어시스턴트에게 수정을 요청하실 때, 아래 템플릿처럼 명칭을 조합하여 말씀해 주시면 오해 없이 100% 정확하게 작업됩니다:

* **예시 1 (답장 바 관련)**:
  > *"플로팅 답장 바의 전송 버튼 색상을 파란색으로 바꾸고, 입력 필드 글씨 크기를 14sp로 키워줘"*
* **예시 2 (메시지 말풍선 관련)**:
  > *"알림 카드의 메시지 말풍선 영역에서 발신자 라벨 뒤에 콜론(:) 대신 괄호를 써줘"*
* **예시 3 (패널 헤더 관련)**:
  > *"패널 헤더의 '모두 지우기' 버튼 아이콘을 쓰레기통 모양으로 변경해줘"*
* **예시 4 (설정 화면 관련)**:
  > *"설정 화면의 패널 디자인 카드에 패널 배경색을 커스텀할 수 있는 컬러 피커를 추가해줘"*
