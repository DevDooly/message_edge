# Slivue 다국어 지원 가이드

## 1. 지원 범위

`v1.3.20`부터 한국어와 영어를 지원한다. 기기 언어를 따르며 Android 13 이상은 시스템의 앱 언어 설정에서 Slivue만 별도 선택할 수 있다. Android 8~12에는 이번 변경에서 별도 앱 내부 언어 선택기를 추가하지 않았다.

설정 카드, 권한 안내, 핸들·라이팅·폰트 옵션, 필터, 진단 버튼, 업데이트 진행·검증 오류, 알림 패널, 빠른 답장, 접근성 설명, 테스트 알림과 포그라운드 알림을 현지화한다. 긴 영어 문구는 제목 폭과 버튼 높이를 조정해 기존 기능을 유지한다.

실제 알림 제목·본문·발신자·빠른 답장, 앱 이름, 사용자 폰트 이름, 차단어 및 원격 GitHub 릴리스 노트는 원문을 유지한다. 자동 번역이나 외부 번역 서비스는 사용하지 않는다. 한국어 파서 패턴·내 답장 식별값, 패키지명·설정 저장키·폰트 ID·외부 인텐트·알림 채널 ID는 표시 언어와 무관하게 유지한다.

## 2. 리소스 구조

| 경로 | 역할 |
| --- | --- |
| `app/src/main/res/values/strings*.xml` | 모든 키가 존재하는 영어 기본 리소스 |
| `app/src/main/res/values-ko/strings*.xml` | 한국어 번역 |
| `app/src/main/res/xml/locales_config.xml` | Android 13 이상에 한국어·영어 지원 선언 |
| `strings_appearance.xml` | 핸들·라이팅·폰트·동작 설정 |
| `strings_settings.xml` | 권한·일반 설정·필터·진단 |
| `strings_panel.xml` | 패널·빠른 답장·수량 표현 |
| `strings_parser.xml` | 정보가 없을 때 앱이 생성하는 발신자·대화방 안내 |
| `strings_update.xml` | 업데이트 상태·오류 및 폰트 검증 오류 |

Compose에는 `stringResource`·`pluralStringResource`, 콜백과 서비스에는 현재 `Context`의 리소스를 사용한다. 영어 단·복수는 `plurals`로 구분하고 변수는 `%1$s`, `%1$d` 같은 위치 지정 인수를 사용한다. 코드에서 한국어 문구와 숫자를 이어 붙이지 않는다.

원칙은 영어 기본값을 제공하고 한국어 기기에는 한국어를 보존하는 것이다. 지원하지 않는 언어만 선택한 경우 영어로 표시한다. Android의 언어 우선순위 목록에 지원 언어가 있으면 시스템의 리소스 선택 규칙을 따른다.

## 3. 시각·오류·언어 변경

- 패널의 절대 시각은 현재 리소스 언어와 시스템 12/24시간 설정으로 포맷한다.
- 상대 시각은 해당 언어의 Android ICU를 사용한다. 기기 기본 언어를 강제로 바꾸지 않는다.
- 서비스가 실행 중 구성 변경을 받으면 기존 알림 채널 이름·설명과 실행 알림을 새 언어로 갱신한다. 채널 ID나 중요도를 바꾸지 않는다.
- 업데이트 오류는 리소스 ID와 인수를 보관한 `LocalizedException`으로 전달하고 화면의 현재 언어로 해석한다. 네트워크 예외의 원문은 사용자에게 노출하지 않고 해당 단계의 번역된 안내를 사용한다.
- APK 주소·크기·SHA-256·패키지·버전·서명 검증 조건은 그대로 유지한다.
- 정보가 없는 알림의 `상대방`, `그룹 채팅방`, `외 N명` 표시는 `NotificationLabel` 메타데이터로 구분해 현재 언어로 해석한다. 병합·본문 정제에 쓰는 기존 값은 유지하며, 실제 대화방 이름이 같은 문구여도 임의로 번역하지 않는다.

## 4. 추가 언어 작업 순서

1. 영어 기본 리소스를 기준으로 `values-언어코드`에 번역을 추가한다.
2. 브랜드·패키지·폰트 공급자명·사용자 입력처럼 번역하지 않는 값을 구분한다.
3. 문자열 인수 타입과 순서를 유지한다. 각 언어의 복수형 규칙을 검토하고 `other`를 반드시 제공한다.
4. `locales_config.xml`에 실제 완성한 언어만 추가한다.
5. 언어 리소스 계약 테스트의 검사 대상 언어를 확장한다. 단일 언어, 지역별 변형, 여러 언어의 우선순위, 미지원 언어 폴백을 확인한다.
6. 가장 좁은 패널과 큰 글꼴에서 줄바꿈·버튼·접근성 설명을 확인한다.
7. 아래 빌드를 통과한 뒤 버전·한국어 릴리스 기록을 갱신하고 배포한다.

## 5. 검증과 수동 확인

```powershell
.\gradlew.bat testDebugUnitTest compileDebugKotlin lintRelease assembleRelease
```

자동 검증 대상은 리소스 키·인수 일치, 한국어·영어·미지원 언어 선택, 실제 Compose 카드의 표시·상호작용, 패널 날짜·복수형 및 업데이트 오류다. 기존 알림 파서와 권한 화면 복귀 테스트도 함께 실행한다. 생성 안내와 실제 원문의 구분·언어 변경 후 대화 병합 유지도 검증한다.

Robolectric 4.13의 API 26 날짜 패턴 스텁은 일부 형식을 구현하지 않아, 해당 테스트에서만 Android ICU 패턴 생성기로 연결한다. 앱 코드나 기대 시각을 우회하지 않으며 API 34에는 같은 보완을 적용하지 않는다.

- [ ] One UI에서 앱 언어 한국어 → 영어 → 시스템 기본값 변경
- [ ] Android 8~12에서 기기 언어 변경 후 설정·패널 재열기
- [ ] 서비스가 실행 중일 때 언어 변경 후 시스템 알림과 채널 이름 확인
- [ ] 긴 발신자·영어 안내·큰 글꼴에서 최소 패널 너비 확인
- [ ] 다른 언어로 바꿔도 기존 필터·폰트·권한·메시지 내용 유지 확인
- [ ] 실제 업데이트 다운로드·알 수 없는 앱 설치 설정 복귀 확인

실기기 확인을 수행하지 않은 항목은 완료로 표시하지 않는다. 스크린샷·로그에 실제 개인 대화를 넣지 않는다.

공식 참고: [Android 현지화](https://developer.android.com/guide/topics/resources/localization), [앱별 언어 설정](https://developer.android.com/guide/topics/resources/app-languages).
