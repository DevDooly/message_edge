# 삼성 One UI 릴리스 수동 회귀 체크리스트

## 1. 적용 시점

기능 릴리스 태그를 만들기 전 또는 `minifiedRelease`를 실제 배포 빌드로 승격하기 전에 수행한다. 자동 API 매트릭스가 통과해도 제조사 오버레이·배터리·내비게이션 동작은 실기기에서 별도로 확인한다.

## 3. 설치와 권한

- [ ] 기존 릴리스 위에 설치할 때 앱 데이터가 유지된다.
- [ ] 신규 설치와 업데이트 모두 앱 시작 직후 충돌하지 않는다.
- [ ] 다른 앱 위에 표시 권한을 허용·취소한 뒤 설정 화면 상태가 복귀 시 갱신된다.
- [ ] 알림 접근 권한을 허용·취소한 뒤 설정 화면 상태가 복귀 시 갱신된다.
- [ ] 배터리 최적화 예외 화면 진입과 복귀가 정상이다.

## 4. 엣지 핸들과 패널

- [ ] 왼쪽·오른쪽 핸들에서 패널이 올바른 방향으로 열린다.
- [ ] 핸들 위치·너비·높이·투명도·색상 변경이 즉시 반영된다.
- [ ] 핸들을 숨겨도 스와이프 터치 영역은 동작한다.
- [ ] 바깥 영역 터치, 닫기 버튼, 반대 방향 드래그로 패널이 한 번만 닫힌다.
- [ ] 홈·최근 앱 전환 시 투명 패널 Activity가 남지 않는다.
- [ ] 상태바와 내비게이션 바가 패널에 가려지지 않는다.

## 5. 뒤로가기와 키보드

- [ ] 3버튼 내비게이션의 뒤로가기 버튼으로 패널이 닫힌다.
- [ ] 스와이프 뒤로가기 제스처로 패널이 닫힌다.
- [ ] 빠른 답장 중 첫 번째 뒤로가기는 키보드와 답장 바만 닫는다.
- [ ] 두 번째 뒤로가기는 패널을 닫는다.
- [ ] 답장 전송 후 키보드 포커스와 패널 포커스가 정상 해제된다.
- [ ] 한글·영문·이모지·여러 줄 입력과 전송이 정상이다.

## 6. 알림과 필터

- [ ] 카카오톡 등 1:1 대화에서 발신자 이름이 본문에 중복 표시되지 않는다.
- [ ] 단체 대화에서 화자 라벨과 메시지 순서가 유지된다.
- [ ] 동일 시각·동일 본문의 서로 다른 발신자 메시지가 사라지지 않는다.
- [ ] 앱 제외와 키워드 차단이 즉시 적용되고 재시작 뒤 유지된다.
- [ ] 모두 지우기와 개별 지우기가 상태바 알림과 의도대로 연동된다.
- [ ] 진단 모드를 끄면 복사 버튼이 숨겨지고 메모리 덤프가 제거된다.

## 7. 서비스와 제조사 정책

- [ ] 화면 꺼짐·켜짐과 앱 백그라운드 전환 뒤 핸들이 유지된다.
- [ ] 재부팅 뒤 설정값에 따라 서비스가 복구된다.
- [ ] 절전 모드와 배터리 최적화 상태에서 비정상 종료가 없다.
- [ ] Edge Lighting 효과가 화면 모서리와 상태바에 맞게 표시된다.
- [ ] Good Lock One Hand Operation+ 바로가기에서 패널이 한 번만 열린다.
- [ ] 외부 제어 옵트인 전에는 Tasker 브로드캐스트가 무시되고, 허용 후 알려진 명령만 동작한다.

## 8. 미디어와 접근성

- [ ] 유튜브 일시 정지 옵션의 켜짐·꺼짐 동작이 설명과 일치한다.
- [ ] 패널을 열고 닫을 때 원치 않는 PiP 전환이나 전체화면 잔상이 없다.
- [ ] 시스템 글꼴 크기 100%·150%에서 주요 버튼과 텍스트가 잘리지 않는다.
- [ ] TalkBack으로 닫기·설정·지우기·답장·전송 버튼의 설명을 읽을 수 있다.
- [ ] 고대비 또는 다크 모드에서 핵심 상태 색상과 텍스트를 구분할 수 있다.

## 9. 승인 기준

- 모든 필수 항목이 통과해야 `minifiedRelease`를 배포 `release`로 승격할 수 있다.
- 실패 항목은 모델·API·One UI 버전·재현 절차·로그와 함께 `docs/PENDING_ISSUES.md`에 기록한다.
- API 26·31·34·35 자동 계측 테스트 결과와 이 문서의 실기기 결과를 릴리스 기록에 함께 남긴다.
