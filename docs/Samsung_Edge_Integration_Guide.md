# 삼성 갤럭시 기본 Edge 및 Good Lock 연동 가이드

과거 갤럭시 스마트폰에서 제공되었던 공식 Notification Edge 패널의 기술적 배경과, 최신 One UI 갤럭시 환경에서 기본 시스템 기능처럼 일체감 있게 연동하여 사용하는 최적의 설정 방법을 안내합니다.

---

## 1. 왜 삼성 기본 엣지 패널 목록에 서드파티 앱을 직접 추가할 수 없나요?

### 기술적 배경

- **과거 (Galaxy S6 Edge ~ S9 / Android 8~9)**:
  - 삼성이 공식적으로 `Samsung Look SDK (Edge Panel API)`를 공개하여, 서드파티 개발자가 만든 알림 엣지, 날씨 엣지 등의 패널을 갤럭시 스토어에서 받아 기본 엣지 패널 목록에 끼워 넣을 수 있었습니다.
- **현재 (One UI 2.5 ~ One UI 6 / 최신 안드로이드 기기)**:
  - 삼성이 `Samsung Look SDK`의 Edge Screen API 지원을 공식 중단(Deprecated)했습니다.
  - 시스템 보안 정책 개편으로 인해 삼성 내부 서명이 없는 외부 서드파티 앱이 시스템 엣지 패널(`CocktailBarService`)로 등록되는 브로드캐스트를 차단했습니다.
  - 이로 인해 과거의 서드파티 엣지 패널들이 갤럭시 스토어에서 모두 사라졌습니다.

---

## 2. 추천 연동 방법 3가지

화면에 별도 핸들을 띄우지 않고, 갤럭시 순정 기능처럼 편리하게 사용하는 3가지 방법입니다.

---

### ⭐ 방법 1. 삼성 Good Lock (One Hand Operation +) 제스처 연동 (가장 추천)

화면에 별도 핸들 바를 띄우지 않고, 제스처만으로 알림 엣지 패널을 호출하는 가장 추천하는 방식입니다.

#### 상세 설정 단계:

1. **앱 설치**:
   - [Google Play Store - One Hand Operation +](https://play.google.com/store/apps/details?id=com.samsung.android.sidegesturepad) 또는 Galaxy Store에서 `Good Lock` 앱과 `One Hand Operation +` 모듈을 설치합니다.

2. **핸들 선택**:
   - `One Hand Operation +` 실행 후 상단 스위치를 켭니다.
   - 평소 자주 사용하는 손의 핸들(`오른쪽 핸들` 또는 `왼쪽 핸들`)을 터치합니다.

3. **제스처 지정**:
   - 삼성 기본 엣지 패널(수평 스와이프)과 겹치지 않는 제스처를 선택합니다.
   - 추천 제스처: `대각선 아래로` 또는 `대각선 아래로 길게 당기기` (또는 `대각선 위로`)

4. **동작 등록**:
   - 선택한 제스처를 누르고 `애플리케이션 실행`을 선택합니다.
   - 앱 목록에서 `Notification Edge`를 선택합니다.
   - (v1.0.3 이상에서는 설정창이 뜨지 않고 알림 엣지 패널만 즉시 열립니다.)

5. **Notification Edge 앱에서 핸들 숨기기**:
   - `Notification Edge` 앱을 실행합니다.
   - `엣지 핸들 설정`에서 `핸들 바 화면 표시`를 OFF로 변경합니다.

6. **실제 사용 및 제스처 닫기**:
   - **열기**: 측면에서 대각선 아래로 스와이프하면 테두리 라이팅과 함께 알림 패널이 열립니다.
   - **닫기**: 패널 화면을 터치 후 왼쪽으로 드래그하거나, 바깥 투명 화면을 터치하면 닫힙니다.

> 💡 **사용 효과 요약**:
> - 수평 스와이프: 삼성 기본 엣지 패널 사용
> - 대각선 스와이프: 알림 엣지 패널 즉시 호출
> - 화면에 불필요한 바가 없어 100% 순정 같은 일체감 제공

---

### 방법 2. 갤럭시 기본 [애플리케이션 엣지 패널]에 바로가기 등록

기본 엣지 패널의 첫 페이지인 '애플리케이션 패널' 안에 Notification Edge를 추가하는 직관적인 방법입니다.

#### 설정 단계:
1. 갤럭시 측면의 기본 Edge 패널을 열고 하단의 `연필(편집)` 아이콘을 누릅니다.
2. 앱 목록에서 `Notification Edge`를 찾아 기본 엣지 패널 즐겨찾기 목록에 추가합니다.
3. Notification Edge 앱 설정에서 `핸들 바 화면 표시`를 OFF로 변경합니다.

> 💡 **사용 효과**: 기본 엣지 패널을 열어 알림 엣지 아이콘을 터치하면 즉시 반투명 알림 패널이 뜹니다.

---

### 방법 3. 물리적 위치 분리 배치 (좌/우 또는 상/하 분리)

본 앱의 플로팅 핸들을 사용하면서 기본 엣지와의 터치 간섭을 없애는 설정입니다.

- **옵션 A: 좌/우 분리 (양손 제스처)**:
  - 갤럭시 기본 Edge: 화면 우측(Right) 유지
  - Notification Edge: 앱 설정에서 `왼쪽 (Left)` 선택
  - 오른쪽은 기본 도구 패널, 왼쪽은 알림 엣지로 분리
- **옵션 B: 상/하 높이 분리 (동일 방향 사용 시)**:
  - 갤럭시 기본 Edge: 시스템 설정에서 핸들 위치를 상단(20~30%)으로 이동
  - Notification Edge: 앱 설정에서 핸들 위치를 하단(70~80%)으로 설정
  - 아래쪽은 알림 엣지, 위쪽은 기본 도구 패널로 구분

## 3. 자주 묻는 질문 (FAQ)

**Q. 알림이 올 때 테두리가 빛나는 엣지 라이팅(Edge Lighting)만 쓰고 싶어요.**  
A. 앱 설정에서 `핸들 바 화면 표시`를 끄고 `엣지 라이팅`만 켜두시면, 알림 수신 시 화면 테두리에 네온 라이팅 효과만 표시됩니다.

**Q. 카카오톡 대화방별 과거 메시지도 모아서 볼 수 있나요?**  
A. 네, 단체 대화방이나 개인톡의 과거 대화 내역(최대 50개)이 차곡차곡 누적되며, `이전 대화 더보기` 버튼을 통해 전체 대화를 확인할 수 있습니다.

**Q. 스마트폰을 재부팅해도 서비스가 유지되나요?**  
A. 네, 재부팅 후에도 권한이 허용되어 있다면 백그라운드에서 자동으로 서비스가 실행됩니다.

**Q. APK 설치 시 보안 위험으로 차단된다고 나와요.**  
A. 삼성 One UI 6.0+의 경우 스마트폰 `설정` ➔ `보안 및 개인정보 보호` ➔ `보안 위험 자동 차단`을 `사용 안 함(OFF)`으로 꺼주시고, `출처를 알 수 없는 앱 설치`에서 해당 앱(내 파일, 브라우저 또는 Notification Edge)을 허용해 주시면 됩니다.

**Q. 상단 바에 '다른 앱 위에 표시됨' 시스템 알림이 계속 떠요.**  
A. 아래 2가지 방법 중 하나로 깔끔하게 영구 제거하실 수 있습니다:
1. **상단 바에서 바로 끄기**: 해당 알림을 길게 꾹 누른 뒤 `[알림 끄기]` ➔ `적용` 터치
2. **설정에서 끄기**: `설정` ➔ `애플리케이션` ➔ `시스템 앱 표시 ON` ➔ `Android 시스템` ➔ `알림` ➔ `알림 카테고리` ➔ `다른 앱 위에 표시되는 앱` OFF
*이 설정은 Android 시스템의 오버레이 안내 알림만 끄는 것이므로, 알림 엣지 앱의 모든 기능은 100% 정상 작동합니다.*
