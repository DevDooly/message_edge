# 📱 삼성 갤럭시 기본 Edge 및 Good Lock 완벽 연동 가이드

과거 갤럭시 스마트폰(Galaxy S6 ~ S9 / Android 8~9)에서 지원되던 공식 Notification Edge 패널의 기술적 배경과, 최신 One UI 갤럭시 환경에서 기본 시스템 기능처럼 깔끔하게 연동하여 사용하는 최적의 설정 방법을 상세히 안내합니다.

---

## 🔍 1. 왜 삼성 기본 엣지 패널 목록에 서드파티 앱을 직접 추가할 수 없나요?

### 📜 기술적 배경

* **과거 (Galaxy S6 Edge ~ S9 / Android 8~9 시절)**:
  * 삼성이 공식적으로 **`Samsung Look SDK (Edge Panel API / Sapa SDK)`**를 공개하여, 서드파티 개발자가 만든 알림 엣지, 날씨 엣지 등의 플러그인을 갤럭시 스토어에서 다운로드받아 기본 엣지 패널 목록에 직접 추가할 수 있었습니다.
* **현재 (One UI 2.5 ~ One UI 6 / 최신 안드로이드 기기)**:
  * 삼성이 **Samsung Look SDK의 Edge Screen API 지원을 공식 중단(Sunset & Deprecated)**했습니다.
  * One UI의 시스템 보안 및 권한 정책이 개편되면서, 삼성 내부 시스템 서명이 없는 **외부 서드파티 앱이 시스템 엣지 패널(`CocktailBarService`)로 등록되는 브로드캐스트를 완전히 차단**했습니다.
  * 이로 인해 과거의 서드파티 엣지 패널 앱들이 갤럭시 스토어에서 모두 사라지게 되었습니다.

---

## 🏆 2. 추천 연동 방법 3가지

화면에 불필요한 핸들을 띄우지 않고, 마치 갤럭시 순정 기능처럼 일체감 있게 사용하는 3가지 최적 설정 방법입니다:

---

### ⭐ 방법 1. 삼성 Good Lock [One Hand Operation +] 제스처 연동 (가장 추천 / 100% 순정 일체감)

갤럭시 유저들이 가장 선호하는 최고의 방식입니다. 화면에 어떤 핸들 그래픽도 띄우지 않고 **갤럭시 시스템 제스처**를 통해 알림 엣지 패널을 즉시 호출할 수 있습니다.

#### ⚙️ 상세 설정 단계 (Step-by-Step):

1. **Good Lock 및 모듈 설치**:
   * **Galaxy Store**를 실행하고 **`Good Lock`** 앱을 검색하여 설치합니다.
   * Good Lock 실행 후 **`One Hand Operation +`** 모듈을 찾아 설치합니다.

2. **핸들 선택**:
   * **One Hand Operation +**를 실행하고 상단 스위치를 **사용 중(ON)**으로 켭니다.
   * 평소 자주 사용하는 손의 핸들(**오른쪽 핸들** 또는 **왼쪽 핸들**)을 터치하여 설정으로 들어갑니다.

3. **제스처 지정**:
   * 삼성 기본 엣지 패널(`수평으로 당기기`)과 겹치지 않는 제스처를 선택합니다.
   * **가장 추천하는 제스처**: **`대각선 아래로`** 또는 **`대각선 아래로 길게 당기기`** (또는 `대각선 위로`)

4. **동작에 Notification Edge 등록**:
   * 선택한 제스처를 누르고 동작 목록에서 **`애플리케이션 실행`**을 선택합니다.
   * 앱 목록에서 **`Notification Edge`**를 찾아 선택합니다.
   * *(v1.0.3 이상 버전에서는 실행 시 설정창이 뜨지 않고 오직 알림 엣지 패널 오버레이만 0초 만에 즉시 열립니다.)*

5. **Notification Edge 앱에서 핸들 숨기기**:
   * **Notification Edge** 앱을 실행합니다.
   * **`엣지 핸들 설정`** 카드에서 **`핸들 바 화면 표시`** 스위치를 **OFF(끄기)**로 변경합니다.

6. **실제 사용 및 닫기 제스처**:
   * **열기**: 화면 측면에서 지정한 제스처(예: 대각선 아래로 스와이프)를 실행하면 **테두리 엣지 라이팅 네온 애니메이션과 함께 알림 엣지 패널이 슬라이드 아웃**됩니다!
   * **닫기**: 패널 화면을 터치하고 **손가락으로 왼쪽 드래그(스와이프)**하거나, 패널 바깥의 투명한 화면 영역을 가볍게 터치하면 즉시 닫힙니다.

> 💡 **사용 효과 요약**:
> - 평소에는 일반 수평 스와이프로 **삼성 기본 엣지 패널** 사용
> - 대각선 스와이프 시 **테두리 엣지 라이팅 + 알림 엣지 패널** 즉시 호출
> - 화면에 불필요한 플로팅 바가 전혀 없어 100% 순정 같은 완벽한 일체감 제공!

---

### ⭐ 방법 2. 갤럭시 기본 [Apps(애플리케이션) 엣지 패널]에 바로가기 등록

갤럭시 기본 엣지 패널의 첫 페이지인 **'애플리케이션 패널'** 안에 Notification Edge를 추가하는 직관적인 방법입니다.

#### ⚙️ 설정 단계:
1. 갤럭시 화면 측면의 기본 Edge 패널을 열고 하단의 **`연필(편집)`** 아이콘을 누릅니다.
2. 앱 목록에서 **`Notification Edge`**를 찾아 기본 엣지 패널 즐겨찾기 목록에 추가합니다.
3. **Notification Edge** 앱 설정에서 **`핸들 바 화면 표시`**를 **OFF**로 설정합니다.

> 💡 **사용 효과**: 기본 엣지 패널을 열어 알림 엣지 아이콘을 가볍게 터치하면 즉시 반투명 알림 패널이 화면에 뜹니다.

---

### ⭐ 방법 3. 물리적 위치 분리 배치 (좌/우 또는 상/하 분리)

본 앱의 전용 플로팅 핸들을 사용하면서 기본 엣지와 터치 간섭을 없애는 설정입니다.

* **옵션 A: 좌/우 분리 (양손 제스처)**:
  * **갤럭시 기본 Edge 패널**: 화면 **우측(Right)** 유지
  * **Notification Edge 앱**: 앱 설정에서 **`왼쪽 (Left)`** 선택
  * 오른쪽을 당기면 기본 도구 패널, 왼쪽을 당기면 알림 엣지 오픈!
* **옵션 B: 상/하 높이 분리 (동일 오른쪽 사용 시)**:
  * **갤럭시 기본 Edge 패널**: 시스템 설정에서 핸들 위치를 `상단 (20~30%)`으로 이동
  * **Notification Edge 앱**: 앱 설정에서 `상하 위치 조절 슬라이더`를 `70~80% (하단)`으로 설정
  * 엄지손가락이 닿는 아래쪽은 알림 엣지, 위쪽은 기본 도구 패널로 깔끔하게 구분됩니다.

## ❓ 3. 자주 묻는 질문 (FAQ)

**Q. 알림이 올 때 테두리가 빛나는 엣지 라이팅(Edge Lighting)만 쓰고 싶어요.**  
A. 가능합니다! 앱 설정에서 `핸들 바 화면 표시`를 끄고 `엣지 라이팅`만 켜두시면, 알림이 올 때마다 화면 둘레에 은은한 네온 그라데이션 라이팅 효과가 표시됩니다.

**Q. 카카오톡 대화방별 과거 메시지도 모아서 볼 수 있나요?**  
A. 네! `MessagingStyle` 파싱 및 과거 대화 내역 누적 기능이 적용되어 있어, 단체 대화방이나 개인톡의 과거 대화 내역(최대 50개)이 카드 내에 차곡차곡 누적되며, `▼ 이전 대화 더보기`를 눌러 전체 대화를 언제든 확인할 수 있습니다.

**Q. 스마트폰을 재부팅해도 서비스가 유지되나요?**  
A. 네, `BootReceiver`가 내장되어 있어 재부팅 후에도 권한이 허용되어 있다면 백그라운드에서 자동으로 서비스가 실행됩니다.
