# Slivue v1.3.23

엣지 패널을 열 때 상태바 시계와 아이콘이 배경에 묻히던 문제를 수정했습니다.

- 어두운 화면에서는 밝은 아이콘, 밝은 화면에서는 어두운 아이콘 등 아래 앱의 기존 상태바 표시를 유지합니다.
- 패널 제목·알림 개수·조작 아이콘의 한 줄 정렬과 기존 패널 위치를 유지합니다.
- 투명 액티비티 구조와 시스템 뒤로가기, 설정·닫기, 답장 키보드 동작을 유지합니다.
- Galaxy S23 Ultra의 Android 16 / One UI 8.5에서 업데이트 설치와 밝은·어두운 배경을 확인했습니다.

기존 앱 위에 업데이트할 수 있으며 패키지 이름·저장 데이터·서명 계보는 변경하지 않았습니다. 빌드 번호는 153입니다.

검증: 단위·회귀 검사 174개, Android 8·16 가상 기기 계측 테스트 각각 5개 통과. Lint 오류 0개이며 기존 경고 63개는 남아 있습니다.

실제 대화 전송이나 기존 사용자 알림 삭제는 시험하지 않았습니다. 상세 결과는 [삼성 실기기 시험 보고서](https://github.com/DevDooly/message_edge/blob/main/docs/GALAXY_S23_TEST_REPORT.md)를 참고하세요.
