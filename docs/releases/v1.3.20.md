# Slivue v1.3.20 — 한국어·영어 지원

## 주요 변경

- 설정·권한·핸들·라이팅·폰트·필터·업데이트·알림 패널에 영어를 추가했습니다.
- 한국어 기기에서는 기존 한국어 화면을 유지합니다. Android 13 이상은 시스템의 앱 언어 설정에서 Slivue만 별도로 선택할 수 있습니다.
- 영어의 단·복수, 언어별 날짜·상대 시각과 시스템 12/24시간 설정을 반영했습니다.
- 큰 글꼴에서 긴 영어 안내를 읽을 수 있도록 일부 제목과 버튼의 배치를 조정했습니다.
- 실제 메시지·발신자·대화방 이름은 번역하지 않습니다. 정보가 없을 때 앱이 생성하는 안내만 언어에 맞게 표시합니다.
- 업데이트의 주소·SHA-256·패키지·버전·서명 검증은 유지하면서 오류 안내를 현지화했습니다.

## 사용 방법

- Android 13 이상: 기기 설정에서 `앱 → Slivue → 언어` 또는 `시스템 → 언어 → 앱 언어`를 확인하세요. 메뉴 위치는 제조사에 따라 다를 수 있습니다.
- Android 8~12: 기기 언어를 한국어 또는 영어로 설정하세요. 별도의 앱 내부 언어 선택 메뉴는 없습니다.
- 기존 앱을 삭제하지 말고 APK로 업데이트하세요. 패키지 식별자와 서명 계보는 유지했습니다.

## 검증 범위

언어 리소스·화면·시간·오류·알림 파서·권한 복귀를 포함한 로컬 테스트 158개를 통과했습니다. 삼성 One UI 실기기의 언어 메뉴와 실제 화면 확인은 별도로 필요합니다.

자세한 안내는 [다국어 지원 가이드](https://github.com/DevDooly/message_edge/blob/main/docs/LOCALIZATION_GUIDE.md)를 참고하세요.
