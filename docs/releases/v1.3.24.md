# Slivue v1.3.24

One Hand Operation+ 제스처로 Slivue를 열 때 영상이 작은 PiP 창으로 바뀌던 문제에 대응했습니다.

## 한 번만 설정해 주세요

1. 업데이트 후 Slivue를 한 번 실행합니다.
2. One Hand Operation+에서 사용 중인 핸들·제스처를 선택합니다.
3. `홈 화면 바로가기 → Slivue: 알림 패널 열기`를 선택합니다.
4. Slivue의 `패널 열기 전 영상 일시 정지`를 켜고 알림 접근 권한을 허용합니다.

기존 `앱 실행 → Slivue` 선택은 자동으로 바뀌지 않습니다. 그 경로에서는 PiP가 발생할 수 있습니다. 목록에 없다면 Slivue를 실행한 뒤 바로가기 목록을 다시 열어 주세요.

## 변경 사항

- 시스템 앱 바로가기 등록을 추가하고, 업데이트·언어 변경 시 표시 이름을 갱신합니다.
- 패널을 열기 전에 지원되는 영상 앱의 일시정지를 요청하고 정지 상태를 확인합니다.
- 이미 멈춘 영상은 다시 재생하지 않으며, 전역 재생/정지 키와 패널을 닫은 뒤 자동 재생을 사용하지 않습니다. YouTube Music·Spotify 등 지정된 음악 앱은 제외합니다.
- 준비 중 중복 실행과 닫은 뒤 늦게 열리는 동작을 방지합니다.
- 기존 패널의 한 줄 헤더, 투명 창, 시스템 뒤로가기와 답장 키보드 구조를 유지합니다.

Galaxy S23 Ultra / Android 16 / One UI 8.5에서 사용자가 실제 목록 표시와 제스처 실행 시 PiP 전환 없음을 확인했습니다. 모든 영상 앱·기기·실행 경로를 보장하는 것은 아닙니다.

기존 설치 위에 업데이트할 수 있으며 패키지 식별자·저장 데이터·서명 계보는 유지합니다. 빌드 번호는 154입니다.

검증: 단위·회귀 207개, Android 8·16 계측 각각 5개 통과. 일반·축소 APK 빌드와 서명 검증, CI의 Android 8·15 기존 설치 업데이트 검증을 통과했으며 Lint 오류는 없습니다.

상세 검증과 알려진 제한: [PiP 대응 작업 기록](https://github.com/DevDooly/message_edge/blob/main/docs/PIP_MITIGATION_WORKLOG.md).
