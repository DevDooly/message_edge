# Slivue v1.3.21 — 미드나이트 레일 디자인

- 앱 아이콘과 어울리는 네이비 배경·블루 포인트·아이보리 글자로 화면을 정리했습니다.
- 설정 화면에 기존 Slivue 아이콘, 핸들 미리보기, 기능별 접이식 메뉴를 적용했습니다.
- 알림 카드·빠른 답장·폰트·필터·권한·업데이트 화면의 색상과 간격을 통일했습니다.
- 좁은 패널에서 헤더 버튼이 겹치지 않도록 배치하고 주요 답장 버튼의 터치 영역을 넓혔습니다.
- 기존 핸들 색상·위치·크기와 사용자 설정, 메시지 처리 및 한국어·영어 지원을 유지합니다.

기존 앱을 삭제하지 말고 업데이트하세요. 삼성 One UI·Good Lock과 실제 메신저의 실기기 확인은 별도로 필요합니다.

162개 자동 테스트, 일반·축소 빌드 및 서명 검사, Android 16 가상 기기의 화면과 업데이트 설치를 확인했습니다. [실제 화면과 디자인 기준](https://github.com/DevDooly/message_edge/blob/main/docs/MIDNIGHT_RAIL_DESIGN.md)을 참고하세요.
