# Slivue v1.3.22 — 엣지 패널 헤더 한 줄 정렬

- 엣지 패널 상단의 앱 이름·알림 개수·모두 지우기·설정·닫기 버튼을 한 줄로 정렬했습니다.
- 패널 폭에 따라 버튼 가로 폭과 제목 크기를 조정하고, 큰 글꼴에서도 줄바꿈이나 버튼 겹침을 방지했습니다.
- 버튼 높이는 48dp로 유지하며 각 버튼의 터치 영역이 이웃 버튼을 침범하지 않도록 했습니다.
- 기존 알림 카드, 저장된 패널 폭·위치·색상, 권한과 답장 처리 방식은 변경하지 않았습니다.

기존 앱을 삭제하지 말고 업데이트하세요. 매우 큰 글꼴이나 긴 알림 개수는 일부 말줄임으로 표시될 수 있으며 접근성 텍스트는 유지합니다.

164개 자동 테스트와 일반·축소 빌드 및 서명 검증을 통과했습니다. Android 16 가상 기기에서 기존 버전 위 업데이트 설치, 기본·최소 폭과 큰 글꼴, 한국어·영어, 지우기·설정·닫기·뒤로가기를 확인했습니다. 삼성 One UI 실기기 확인은 별도로 필요합니다.

[실제 가상 기기 화면과 디자인 기준](https://github.com/DevDooly/message_edge/blob/main/docs/MIDNIGHT_RAIL_DESIGN.md)을 참고하세요.
