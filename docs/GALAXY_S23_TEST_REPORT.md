# Galaxy S23 Ultra 실기기 시험 결과

## 최초 시험 환경과 범위 — v1.3.22

- 시험일: 2026-09-10
- 기기: Galaxy S23 Ultra, SM-S918N
- 운영체제: Android 16 / API 36, One UI 8.5(시스템 속성 `80500`)
- 화면: 1080×2316, 밀도 450dpi, 3버튼 내비게이션
- 앱: 공개 릴리스 Slivue v1.3.22 / 빌드 152
- 설치: 이 기기에는 앱이 없어 신규 설치했다. 이 기기에서 기존 버전 위 업데이트를 검증한 것은 아니다.
- 사전 조건: 사용자가 USB 디버깅을 승인했고, 설치 후 오버레이·알림 접근 권한의 허용 상태를 확인했다.
- 범위: 엣지 패널 헤더 수정에 대한 실제 화면·기본 조작 회귀 검사. 전체 One UI 출시 체크리스트 완료를 의미하지 않는다.

## 발견한 문제

**어두운 Slivue 설정 화면 위에서 패널을 열면 상태바 시계·일부 아이콘이 검게 바뀌어 가독성이 낮아진다.**

- 재현: 시스템 밝은 모드에서 Slivue 설정 → 패널 열기.
- 관찰: 설정 화면에서는 흰색이던 상태바 시계가 패널을 열면 어두운 배경 위 검은색으로 표시된다.
- 코드상 원인 후보: `EdgePanelActivity`가 `SystemBarStyle.auto`의 아이콘 명암을 시스템 다크 모드만으로 결정하고, 투명 창 아래의 실제 배경은 고려하지 않는다. `Theme.kt`의 일반 설정 화면은 밝은 상태바 아이콘을 지정한다.
- 헤더 한 줄 정렬과는 별개의 문제다. 이번 시험에서 발견했으며 발생 시점이나 이전 버전 대비 회귀 여부는 확인하지 않았다.
- 최초 시험에서는 코드 수정·새 릴리스를 수행하지 않고 [이슈 #3](PENDING_ISSUES.md)에 기록했다. 이후 승인받아 수행한 수정 결과는 아래 v1.3.23 재시험에 구분했다.

## 미실시 항목

- 실제 메신저 대화 열기·답장 전송·기존 사용자 알림 전체 삭제.
- 제스처 내비게이션으로 설정 변경 후 시스템 뒤로가기 검사, 오른쪽 핸들 검사.
- Good Lock 바로가기, 동영상/PiP, 재부팅·절전·장시간 백그라운드 검사.
- 이 기기의 기존 앱 위 업데이트 설치, 권한 철회·재허용의 전체 조합, TalkBack 실제 읽기.

## 시험 후 정리와 자료

- 패널 폭은 260dp, 시스템 글꼴은 100%로 복원했다. 내비게이션 설정은 변경하지 않았다.
- 추가한 `Slivue-Test` 시험 알림 한 건만 개별 삭제했다. 실제 메시지를 전송하거나 기존 사용자 알림을 삭제하지 않았다.
- 설치한 공개 v1.3.22는 휴대폰에 유지했다. USB 디버깅은 사용자 설정을 임의로 해제하지 않았다.
- 화면 캡처는 저장소에서 제외되는 `app/build/manual-tests/galaxy-s23/`에만 보관했다. 캡처에는 Slivue 화면과 합성 시험 알림만 포함한다.
- 이번 작업에서는 앱 소스 변경·재빌드·재배포 없이 공개 APK를 직접 시험했다.

## v1.3.23 수정 후 재시험 — 2026-09-10

- 동일 기기에 v1.3.22 → v1.3.23 / 빌드 153을 `adb install -r`로 업데이트했다. 앱 삭제·데이터 초기화 없이 기존 권한과 설정이 유지됐다.
- 시스템 바를 덮지 않는 투명 액티비티 창으로 변경했다. 아래 앱의 바 색상과 아이콘 명암을 그대로 사용하며, 흰색 아이콘을 일괄 강제하지 않는다.
- 시스템 밝은 모드에서 **어두운 Slivue 설정 위 패널은 흰색 시계·아이콘**, **밝은 삼성 디스플레이 설정 위 패널은 검은색 시계·아이콘**임을 화면과 시스템 창 표시 정보로 확인했다. 내비게이션 바 표시 주체도 각각 아래 설정 액티비티로 유지됐다.
- 기본 폭 260dp에서 제목·알림 개수·세 아이콘이 같은 행으로 유지됐다. 제목 중심 223.5px, 아이콘 중심 224px로 기존 위치와 동일하다.
- 헤더 설정·닫기, 삼성 3버튼 뒤로가기, 바깥 터치 닫기와 왼쪽 핸들 스와이프 열기를 재확인했다. 삼성 시스템의 내비게이션 방식·글꼴·밝은 모드 설정은 바꾸지 않았다.
- Android 8 / API 26 및 Android 16 / API 36 가상 기기에서 창 폭·안전 영역·한 줄 헤더와 합성 답장의 키보드 표시·입력·뒤로가기 숨김을 포함한 계측 테스트 각각 5개를 통과했다. 실제로 키보드가 열린 화면도 확인했다. 실기기에서 실제 대화에 답장을 전송한 시험은 아니다.
- 최종 로컬 단위·회귀 검사 174개 통과, Lint 오류 0개·기존 경고 63개이며 일반·축소 APK 빌드와 기존 서명 계보 검증을 통과했다.
- 실기기 캡처는 공개 저장소에 포함하지 않는 `app/build/manual-tests/status-bars/`에만 보관했다. 이 재시험 화면에는 OS 안내 알림이 포함될 수 있으며 기존 알림을 삭제하거나 메시지를 전송하지 않았다.
- 분할 화면·가로 회전·몰입 모드·전체 One UI 출시 체크리스트 및 장시간 안정성은 이번 수정의 검증 범위 밖이다. 최초 시험의 미실시 항목 중 업데이트 설치만 이번에 추가 확인했다.
